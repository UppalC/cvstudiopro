Owner Order Tools

Launch version: orders come through WhatsApp. Use builder owner mode to import structured order text or order files.

How to process an order

  1. Open the WhatsApp order message.
  2. Confirm payment has been received.
  3. Open your Google Sheet, go to the Codes tab, and add a new row with a unique code for this order (e.g. CVPRO-4F82K). Leave the "used" column blank.
  4. Send that exact code to the customer on WhatsApp. They enter it in the "Order / Payment Options" popup to unlock Print/Export themselves. Each code works once only — the Sheet marks it used automatically.
  5. Optional: if you want to prepare/export the CV yourself instead, click Open Owner Builder below (your login stays active for this browser tab), paste the structured order text into Owner Order Tools, click Import Order Text, then Export PDF/Word and send it to the customer.
