How to process an order

Orders can arrive two ways now:

  1. Submitted Online — these appear automatically in the Orders list below. Confirm payment has been received (checked manually, same as before), then click Approve & Send Code — this assigns the next unused code from the Codes tab and emails it to the customer automatically. Nothing else to do.
  2. Sent on WhatsApp (older method, still works) — open your Google Sheet, go to the Codes tab, add a new row with a unique code (e.g. CVPRO-4F82K, "used" column left blank), and send that exact code to the customer on WhatsApp. Each code works once only.
  3. Optional: if you want to prepare/export the CV yourself instead, click Open Owner Builder below (your login stays active for this browser tab), paste the structured order text into Owner Order Tools, click Import Order Text, then Export PDF/Word and send it to the customer.
