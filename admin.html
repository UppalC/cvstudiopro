Templates: Free ya Premium

Har template ke samne Free ya Premium dabayen. Neeche password daal kar Control Save karein dabayen, tab website par tabdeeli aati hai (1-2 minute). Peela (zard) kaarda matlab is template ko aap ne default se badla hai.

Sach baat: Free/Premium ka lock browser mein chalta hai (website ke code mein), server par nahi. Yani ye ek business ka switch hai, koi mazboot tala nahi. Koi tech-savvy shakhs premium ko free karwa sakta hai. Paison ka asal mamla (code check) server par hi hota hai, aur is ke liye yeh switch theek hai.

Site ka naam

Kya badlega: har page ke upar wala naam aur neeche footer ka naam. Kya NAHI badlega: Google search mein dikhne wala title, page ka description, sharing image aur domain (github.io address). Wo sab abhi code mein likhe hain; naam final hone par hum aik alag batch mein sab badlenge.

Demo video (Guide page par)

Video direct yahan upload kyun nahi: admin panel ka server (Google Apps Script) bari video file nahi sambhal sakta, aur website ka free hosting bhi bari video ke liye theek nahi. Isliye video pehle YouTube par daalein, phir uska link yahan paste karein.

  1. youtube.com kholein, apne Google account se login karein.
  2. Upar Create (ya + ka button) dabayen, phir Upload video.
  3. Video chunein. Visibility mein Unlisted chunein (sirf link walay dekh saken ge) ya Public.
  4. Upload poora hone par video ka link copy karein aur upar wale box mein paste karein.
  5. Google Drive se bhi chal sakta hai: file par right click, Share, "Anyone with the link" karein, link paste karein. YouTube behtar chalta hai.

Settings kaise bharein (step by step)
  1. WhatsApp number: wo number likhein jis par aap orders lena chahte hain. 0300... ya 92300... dono chalte hain, save par khud sahi format ban jata hai.
  2. Contact email: sirf website par dikhane ke liye hai. Customer ko jo emails jati hain wo us Google account se jati hain jis ne Apps Script banaya hai, is address se nahi.
  3. Prices: "Premium CV price" mein wo qeemat likhein jo customer ko abhi deni hai (jaise Rs. 700). Purani qeemat tab hi likhein jab wo waqai pehle thi.
  4. Payment tareeqe (1 se 3): har tareeqe mein naam (JazzCash, EasyPaisa ya bank ka naam), account par likha naam, number ya IBAN aur chhoti hidayat likhein. Number do dafa khud check karein: customer yahi number dekh kar paise bhejta hai.
  5. QR (optional): apni payment app mein se QR ki screenshot ya image save karein (jahan apni app mein QR dikhta hai) aur yahan PNG ya JPG upload karein. Image khud chhoti ho jati hai. App ke menu ke naam badalte rehte hain, is liye apni app mein "QR" ya "receive money" jaisa option dhoondein.
  6. Offer / Free trial: offer ke saath khatam hone ki tareekh zaroor daalein. Free trial ON karne se saare premium free ho jate hain, is liye iski bhi tareekh rakhein.
  7. Save: sab se neeche apna Owner Password daal kar "Settings Save karein" dabayen. Payment ya WhatsApp badalne par aap ko hifazat ke liye alert email bhi aayegi.
  8. Save ke baad apne dusre number ya email se aik test order bhej kar poora raasta dekh lein (order, payment page, approve, code).

Purana customer data hatayen (privacy)

Privacy policy mein likha hai ke orders ka data 12 mahine tak rakha jata hai. Ye button 12 mahine se purane orders ka naam, WhatsApp, email, note aur transaction ID mita deta hai. Order number, template, status aur code rehte hain. Ye wapas nahi aata. Mahine mein aik dafa chalana kafi hai.

Owner password badlein

Madad: order ka kaam kaise hota hai
  1. Naya order aata hai: payment check karein, phir Approve & Send Code dabayen. Agle unused code customer ko email ho jata hai. Agar email nahi di thi to WhatsApp par code bhejein wala button dabayen.
  2. Code bheja: customer code daal kar khud CV download kar leta hai. Agar aap khud CV bana kar dena chahte hain to Kaam shuru dabayen.
  3. Kaam jari hai: jab CV de dein to Mukammal dabayen.
  4. Codes khatam hon to khud naye ban jate hain (approve karte waqt). Chahein to Settings tab se pehle se bhi bana sakte hain.
  5. Har status Google Sheet ke Orders tab mein save hota hai, isliye phone aur laptop dono par same nazar aata hai.
