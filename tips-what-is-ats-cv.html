What is an ATS, and how to make an ATS-friendly CV

Many companies use software to receive and sort applications. If the software cannot read your CV properly, a person may never see it. Here is how to avoid that.

What is an ATS?

ATS stands for Applicant Tracking System. It is software that companies use to collect job applications, store them, and help recruiters search and filter them. When you apply through a company website or a job portal, your CV often goes into a system like this first.

Different systems work differently, and companies set them up in different ways. So nobody can promise that one format will pass every system. What we can say is that some layouts are easier for software to read than others.

What can go wrong

An ATS reads the text in your file and tries to sort it into fields such as name, job titles, dates and skills. Problems can happen when:

  • Important text is inside an image or a picture of text. Software cannot read pictures well.
  • The layout uses many columns, boxes, tables or text boxes, so the reading order gets mixed up.
  • Contact details are placed only in the header or footer area, which some systems skip.
  • Headings have unusual names, so the system does not recognise the section.
  • Fancy symbols or icons replace normal words.

Simple rules for an ATS-friendly CV

  1. Use a clear, one-column or simple layout. Name at the top, then summary, experience, education, skills.
  2. Use standard headings such as Summary, Experience, Education and Skills.
  3. Write text as real text. Do not put your skills or job history inside an image.
  4. Put contact details in the main body at the top of the page.
  5. Use common fonts and a readable size.
  6. Write dates in one consistent style, for example Jan 2022 – Mar 2024.
  7. Match the job advertisement honestly. If the ad asks for “customer service” and you have that experience, use those same words. Do not add skills you do not have.
  8. Follow the file type the employer asks for. If the ad says Word, send Word. If it does not say, a PDF made from real text is usually fine, but a scanned or image-only PDF is not.

Do you have to give up good design?

Not always. A person will read your CV after the software, so it should also look good. A clean design with a little colour in the headings is normally fine. The risky part is complicated layout: sidebars full of boxes, text over pictures, or heavy graphics. If you are applying through an online system, choose a simple design. If you are handing a CV to someone directly, or sending it to a person by email, a more designed layout is a reasonable choice.

A quick self-check

Open your CV PDF, select all the text with your mouse and copy it into a plain text file. If the text comes out in the right order and nothing important is missing, software will likely read it more easily. If it comes out scrambled or empty, simplify the layout.
